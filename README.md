# SMART STUDY AI Planner

This website allows users to create personalized study plans using AI-powered tools. It's a Progressive Web App (PWA) that can be installed on phones.

## Features

- Interactive study plan generator
- Responsive design
- Smooth navigation
- Installable as PWA on mobile devices
- Offline caching

## Installation

1. Open the website in a mobile browser (Chrome, Safari, etc.).
2. Look for the "Add to Home Screen" option in the browser menu.
3. Follow the prompts to install.

## Files

- `index.html`: The main HTML page with planner form
- `style.css`: CSS styles for the website
- `script.js`: JavaScript for form handling and plan generation
- `manifest.json`: PWA manifest file
- `sw.js`: Service worker for caching
- `icon-192.png`, `icon-512.png`: App icons (replace with actual images)

## How to view

Open `index.html` in a web browser or serve with a local server.
